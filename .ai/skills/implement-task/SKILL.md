# Implement task

1. Read `brief.md` and `plan.md` for the active task.
2. Inspect the current working tree and relevant existing code before editing.
3. Make the smallest change that satisfies the acceptance criteria.
4. Preserve existing public interfaces and conventions unless the plan explicitly changes them.
5. Avoid unrelated cleanup, speculative dependencies, and generated-file edits.
6. Run the narrowest useful checks available.
7. Write `changes.md` with changed files, commands, results, and unresolved concerns.

Do not claim completion until the verification wave has produced evidence.
