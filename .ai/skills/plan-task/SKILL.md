# Plan task

Use this skill at the start of a meaningful task or when the scope changes.

1. Read the task brief and inspect only the files needed to understand the change.
2. State the goal, non-goals, constraints, assumptions, and acceptance criteria.
3. Identify affected files, interfaces, tests, and likely risks.
4. Propose the smallest coherent implementation plan.
5. Record the plan in `.ai/runs/TASK-*/plan.md`.

Do not implement while the scope, owner, or acceptance criteria are materially unclear. Ask one focused question or record the uncertainty and stop at the planning boundary.
